# Lab03 — Addressing Modes

## Goal

Use the same standalone machine to study how the 68000 forms effective addresses.

Lab03 adds no hardware.

Expected output:

```text
03
```

The important evidence is the RAM result area and VCD.

## Test Table

Lab03 first creates three words in RAM:

```text
0x010040   0x1111
0x010042   0x2222
0x010044   0x3333
```

A0 points to:

```text
A0 = 0x010040
```

## Addressing Modes

### Address-register indirect

```asm
move.w (%a0),%d0
```

`(A0)` means memory at the address held in A0.

Expected value:

```text
D0 low word = 0x1111
```

### Post-increment

```asm
move.w (%a1)+,%d1
```

Use the address in A1, then increment A1 by the operand size.

For a word:

```text
read [A1]
A1 = A1 + 2
```

Expected value:

```text
D1 low word = 0x1111
```

### Pre-decrement

```asm
move.w -(%a2),%d2
```

Decrement A2 first, then access memory.

For a word:

```text
A2 = A2 - 2
read [A2]
```

A2 starts at `A0 + 6`, so the read lands at `A0 + 4`.

Expected value:

```text
D2 low word = 0x3333
```

### Displacement

```asm
move.w 2(%a0),%d3
```

Effective address:

```text
A0 + 2 = 0x010042
```

Expected value:

```text
D3 low word = 0x2222
```

### Indexed

```asm
moveq  #4,%d4
move.w 0(%a0,%d4.w),%d5
```

Effective address:

```text
A0 + sign-extended D4.W + displacement
= 0x010040 + 4 + 0
= 0x010044
```

Expected value:

```text
D5 low word = 0x3333
```

The original 68000 index form has no scale factor; the index is added directly.

### Absolute

```asm
move.w 0x010040,%d6
```

The address itself is encoded in the instruction stream.

Expected value:

```text
D6 low word = 0x1111
```

### PC-relative

```asm
move.w rom_word(%pc),%d7
```

The effective address is formed relative to the current PC rather than an address register.

`rom_word` contains:

```text
0x4444
```

Expected value:

```text
D7 low word = 0x4444
```

## Result Area

Each observed value is copied to fixed RAM addresses:

```text
0x010060   0x1111   indirect
0x010062   0x1111   post-increment
0x010064   0x3333   pre-decrement
0x010066   0x2222   displacement
0x010068   0x3333   indexed
0x01006A   0x1111   absolute
0x01006C   0x4444   PC-relative
```

This makes the register results architecturally visible without exposing DUT internals.

```bash
make clean

```

Disassemble:

```bash
make disasm LAB=lab03
```

```bash
surfer logs/lab03/lab03.vcd
```
