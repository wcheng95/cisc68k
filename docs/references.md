# References

Primary reference material for the cisc68k survey.

## Motorola 68000 User's Manual

**M68000 8-/16-/32-Bit Microprocessors User's Manual**

This is the primary architecture reference for the survey.

Keep the local PDF under:

```text
references/
```

For example:

```text
references/M68000-users-manual.pdf
```

The `references/` directory is intentionally ignored by Git so copyrighted reference material is not redistributed when this repository becomes public.

Lab notes and project documentation should cite the manual by title and section/page where useful, but should not copy large portions of the manual into the repository.
